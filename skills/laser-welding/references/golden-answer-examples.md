# Laser Welding Golden Answer Examples

这些样例定义“专业但不复杂”的最终答复风格。它们不是完整工程报告；默认用于普通对话、售前初筛、方案澄清和供应商沟通前的第一版建议。

## Style Contract

- 结论先行：先给门控结论，再给原因与下一步。
- 默认双包：`Decision Pack` + `Engineering / RFQ Pack`。
- 初始启发式推荐默认是 `CONDITIONAL GO`，除非用户提供 DOE 或试焊证据。
- 每个数值带单位，并说明仅作为 DOE / 试焊起点。
- 缺信息时只问一个最高优先级问题，不输出完整方案。
- 不暴露内部工具、调用、fallback、MCP 或编排细节。

## Example 1: Missing Required Input

User:

> 我们想做一条激光焊接线，帮我推荐设备。

Expected answer shape:

```markdown
要先补一个关键信息：请告诉我被焊材料是什么（例如 304 不锈钢、铝合金、紫铜、PC/PA66 等）。

材料决定激光波长、功率段、焊接头、保护气体和 DOE 起点。拿到材料后，我再按“决策包 + 工程/RFQ 包”给你一版可用于内部评审和供应商沟通的建议。
```

Do not:

- 一次追问十几个字段。
- 在材料缺失时给完整 BOM 或最终设备架构。

## Example 2: Minimal New Project

User:

> 1mm 304 不锈钢角焊，主要看强度和外观，怎么选设备？

Expected answer shape:

```markdown
## Decision Pack

结论：CONDITIONAL GO。  
这类 1 mm 304 不锈钢角焊适合先进入打样验证，但还不能直接作为量产放行方案。

主要依据：
- 材料和厚度适合常规光纤激光焊接窗口。
- 强度和外观目标需要通过 DOE 同时验证熔深、焊缝成形、飞溅和氧化。
- 夹具定位、间隙、保护气体和检测标准尚未闭环。

下一步最小闭环：
- 确认焊缝长度、允许间隙、外观验收样板和拉力/截面验收方法。
- 做 6-9 组首轮 DOE，冻结可接受窗口后再进入设备定型。

## Engineering / RFQ Pack

工艺起点：
- 激光：光纤激光，建议从中低功率连续焊窗口打样。
- 参数：功率、速度、离焦和保护气体作为 DOE 主轴；所有数值仅作试焊起点。
- 保护：建议氩气或氮气保护，按氧化和气孔表现收敛。

设备候选：
1. 龙门/直角坐标：适合直线或平面焊缝、节拍稳定、夹具重复性高。
2. 六轴工业机器人：适合空间姿态或多品种切换，但标定和安全集成复杂度更高。

供应商需响应：
- 样件打样报告、截面/拉力/外观记录。
- 夹具定位方案、保护气体方案、安全联锁和配方权限方案。
- DOE 数据表和最终推荐窗口。
```

Do not:

- 写成很长的教材。
- 声称可量产或已验证。
- 只给单一设备方案。

## Example 3: High Takt Requirement

User:

> 铜片搭接焊，目标 2 秒一件，想知道运动方案怎么选。

Expected answer shape:

```markdown
## Decision Pack

结论：CONDITIONAL GO，高节拍可预研，但运动架构必须并行验证。  
2 s/件通常不是单看焊接时间，还要把上料、定位、焊接、检测、下料拆开评估。

关键风险：
- 铜材料反射率和热导率高，工艺窗口窄。
- 高节拍下定位、视觉补偿和检测节拍可能成为瓶颈。
- 夹具一致性不足时，振镜方案会放大位置误差风险。

## Engineering / RFQ Pack

候选架构：
1. 振镜 + 机器人：适合多点位、高速跳转、轨迹重复且视觉定位稳定的工件；若焊点位置漂移大或夹具重复性不足，应降级或增加视觉闭环。
2. 龙门 + 振镜：适合平面阵列焊点和固定工位；若产品换型频繁或空间姿态复杂，应转向机器人方案。
3. 多工位分度盘 + 固定光路：适合品种稳定、节拍强约束；若工件姿态多变，柔性不足。

验证关卡：
- 节拍拆解表达到 2 s/件目标。
- 连续 30-60 分钟热稳定测试。
- 位置偏差、焊点强度、电阻或截面指标满足验收线。
```

Do not:

- 只说“用振镜最快”。
- 忽略上/下料和检测时间。

## Example 4: Battery Copper Ring Gate

User:

> 电池紫铜环焊，厚度 0.4mm，帮我选焊接头。

Expected answer shape:

```markdown
请先提供环焊直径 ringDiameterMm，单位 mm。

电池紫铜环焊的头型和运动架构强依赖直径、同心度、夹具跳动和节拍。在直径未确认前，我不能直接拍板振镜、旋转轴或机器人方案。
```

Do not:

- 在缺少环焊直径时推荐最终头型。
- 同时追问一长串高级参数。

## Example 5: Polymer Transmission Welding

User:

> PC 和 ABS 透射焊，厚度 1.5mm，能不能做？

Expected answer shape:

```markdown
## Decision Pack

结论：CONDITIONAL GO，但必须先确认透光率和吸收层设计。  
PC/ABS 组合可能具备透射焊窗口，但颜色、填料、厚度和波长会显著影响可行性。

缺失闭环：
- 测量上层材料在目标波长下的透光率。
- 确认下层是否具备吸收机制，或是否允许添加吸收剂。
- 用 coupon 试焊验证熔合宽度、气密/强度和外观。

## Engineering / RFQ Pack

建议验证路径：
1. 光学测量：记录透光率、材料颜色、添加剂和厚度。
2. 小样试焊：验证压紧、能量输入和熔合界面。
3. DOE：功率、速度、压紧力、焦点/光斑作为主轴。

设备方向：
- 若透光率满足窗口，可评估近红外透射焊。
- 若透光率不足，需改材料、改吸收层或转其他连接工艺。
```

Do not:

- 只根据材料名直接判定可量产。
- 省略透光率依据。

## Example 6: Defect Diagnosis

User:

> 现在焊缝飞溅多，表面发黑，怎么办？

Expected answer shape:

```markdown
初步判断：先按“能量过高/焦点不稳 + 保护不足”两条线排查，不建议直接只降功率。

优先检查：
1. 焦点位置和光斑：确认焦点漂移、镜片污染、保护镜状态。
2. 单位长度能量：同步看功率、速度、占空比，不单独改一个参数。
3. 保护气体：确认气体类型、流量、覆盖区域和前后送气。
4. 表面状态：油污、氧化膜、镀层会放大飞溅和发黑。

首轮动作：
- 记录当前功率 W、速度 mm/s、离焦 mm、气体 L/min。
- 做 3 组小步收敛：降低线能量、调整离焦、增强保护。
- 用截面、外观、飞溅量和氧化程度决定下一轮，而不是凭肉眼一次拍板。
```

Do not:

- 直接承诺一个参数改动即可解决。
- 忽略清洁、保护气体和光学状态。

## Example 7: Vendor RFQ Request

User:

> 我要找设备商询价，给我一份技术要求。

Expected answer shape:

```markdown
## Engineering / RFQ Pack

供应商必须响应：
- 工艺打样：样件数量、DOE 数据、截面/拉力/外观/电测记录。
- 激光与光学：波长、功率段、光束质量、冷却、防护镜寿命和维护策略。
- 运动与夹具：重复定位、轨迹能力、夹具定位基准、换型方式。
- 检测与安全：视觉/功率/温度或反射光监测，激光安全联锁，权限分级。
- 交付证据：最终参数窗口、报警边界、配方锁定、验收报告模板。

## Decision Pack

结论：先发 RFQ，不直接比价格。  
比较供应商时优先看样件证据、窗口稳定性、节拍拆解和售后交付能力；价格只能在技术方案可比后再评估。
```

Do not:

- 输出价格、报价或成本估算。
- 用品牌名替代技术指标。
